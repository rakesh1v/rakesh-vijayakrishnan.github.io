// about

I ship the layer between hardware and warehouse logic.

I'm an embedded software engineer on the Industrial Robotics team at Leapmile Logistics, where I own the software stack behind an automated storage & retrieval system (ASRS) — from the AGVs that physically move trays, to the pick-to-light displays that guide the humans who work alongside them.

My background spans firmware (C/C++, MicroPython on ESP32 and PIC), motor control, PCB design, and cloud-connected IoT backends. I like problems that sit at the boundary of hardware and software — where a routing algorithm on paper has to survive contact with a real motor, a noisy sensor, and a warehouse full of moving parts.

Before robotics, I spent two years at REON Infotech building and validating embedded control boards from schematic to shipped hardware.

Selected engineering work

Production systems I've designed, built, and shipped inside the ASRS at Leapmile Logistics — plus the embedded groundwork before it.

Fleet Navigation

AGV Fleet & Pathfinding

Line-following AGVs that retrieve trays across the warehouse, localized via RFID-tagged coordinates and routed with Dijkstra's shortest-path algorithm. A Python/Matplotlib tool plots every vehicle's live position on the warehouse map for the team to monitor.

ESP32 · C++RFIDDijkstraMQTTPython / Matplotlib
Pick Automation

Pick-to-Light Display System

Smart display system for ASRS picking stations that lights up the correct rack and quantity per order — with a dedicated "XXXX" safety mode that stops mis-picks outright, driven off the same order data the fleet and arm both consume.

Embedded CMQTT Pub/SubSafety Logic
Motion Planning

SCARA Arm — RRT/RRT* & URDF Sim

A SCARA arm driven by 36V QDD (quasi-direct-drive) motors over CAN bus, automating tray transfer from ASRS racks to the picking station. Pick trajectories are planned with RRT and RRT* against a URDF model of the arm and simulated end-to-end before any path is ever sent to the physical machine.

QDD 36V · CAN BusRRT / RRT*URDF SimulationSCARA
IoT Product

Qikpod Smart Pod Lockers

End-to-end locker product — hardware, firmware, and cloud backend built from scratch. Shipped four distinct access modes (Standard, Ad-hoc, Dynamic, Static) to serve both parcel logistics and self-storage rental use cases.

MicroPythonREST · SwaggerDigitalOceanNginx
Motion Systems

AGV Drive & Motor Control

Full-ownership AGV hardware: 36V BLDC motors with planetary gear reduction for torque under load, driven by an RPM-based closed-loop control algorithm (encoder feedback + PID) rather than open-loop PWM, plus IMU sensor fusion for stable heading and firmware tying sensors, drivers, and comms together over I2C, UART, and SPI.

BLDC · Closed-Loop RPMEncoder + PIDIMU FusionI2C / UART / SPI
Infrastructure

Fleet & Locker Backend

Production backend for locker and fleet management deployed on DigitalOcean — REST APIs documented in Swagger, an MQTT broker handling real-time device traffic, and Linux servers managed over SSH with static IP configuration.

Linux · SSHMQTT BrokerNginxREST API
Foundations · REON Infotech

Industrial Control Boards

Two-layer PCBs designed from schematic to layout for industrial automation products, with PIC16F877A firmware driving the sensing and actuation logic — plus Python/Bash test automation across NodeMCU and ESP32 boards.
